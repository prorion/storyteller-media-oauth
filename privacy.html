Storyteller Media Backup · 시행일 2026-10-19

Storyteller Media Backup은 개인 제작 파일의 보관·복구를 위한 도구입니다. 이 방침은 해당 도구의 Google Drive 연결과 이 안내 사이트에 적용됩니다.

1. 처리하는 정보

  • 사용자가 보관·복구 대상으로 지정한 이미지·음원·영상·문서 및 제작 기록
  • 전송과 무결성 확인에 필요한 파일 이름·ID·상대 경로·크기·해시·작업 결과
  • 계정 확인과 저장 공간 점검에 필요한 Google API 제공 정보
  • Google 접근 권한 유지에 필요한 OAuth 인증 토큰과 앱 자격 증명

2. 사용 목적과 접근 범위

정보는 사용자가 요청한 파일 복사·보관·복구, 계정/용량 확인과 전송 검증에 사용합니다. 앱이 만들거나 사용자가 앱에 허용한 특정 Drive 파일을 다루는 drive.file 권한을 사용합니다. 실제 접근은 사용자의 Google 동의 절차를 따릅니다.

사용자가 승인한 AI 에이전트 작업이 전송 도구를 실행할 수 있습니다. 이 OAuth 연결은 파일 보관·복구 작업에 사용하며, Google 사용자 데이터를 광고·판매 또는 범용 AI 모델 학습 데이터 수집/제공에 사용하는 기능은 두지 않습니다.

3. 저장 위치와 제3자 서비스

제작 파일은 사용자의 로컬 작업 공간과 본인 Google Drive에 보관합니다. 인증 정보는 전송 도구를 실행하는 장치의 로컬 설정에 보관하며 공개 저장소·안내 사이트에 게시하지 않습니다. 이 도구는 별도의 다중 사용자 클라우드 보관 서버를 운영하지 않습니다.

Google은 로그인과 Drive 보관 기능을 제공합니다. 이 앱의 Google API에서 받은 정보 사용은 Google API 서비스 사용자 데이터 정책의 Limited Use 요구사항을 따릅니다.

이 안내 사이트에는 별도의 분석 도구나 정보 입력폼을 두지 않습니다. GitHub Pages 호스팅에는 보안·운영 목적의 접속 로그 처리가 있을 수 있으며 GitHub 개인정보처리방침이 적용됩니다.

4. 보관·삭제와 권한 철회

보관 파일과 복구본의 유지 기간은 사용자가 정한 보관 정책을 따릅니다. Google 계정의 연결된 앱 관리에서 접근 권한을 철회할 수 있고, 사용자는 로컬 인증 설정과 Drive의 보관 파일을 직접 관리·삭제할 수 있습니다. 접근 권한 철회만으로 기존 보관 파일을 자동 삭제하지 않습니다.

5. 문의와 방침 변경

문의는 프로젝트 문의 또는 Google 동의 화면에 표시된 지원 연락처를 이용해 주세요. 공개 문의에는 인증 정보나 개인 파일을 첨부하지 마세요. 처리 범위가 변경되면 이 페이지의 방침과 시행일을 갱신합니다.
