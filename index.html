Storyteller Media Backup

이 도구는 사용자가 제작한 이미지·음원·영상과 제작 기록을 본인의 Google Drive에 보관하고, 필요할 때 내려받아 복구하는 용도로 사용합니다.

주요 기능

  • 사용자가 지정한 제작 파일과 새 버전을 개인 Drive에 복사합니다.
  • 파일 목록과 해시를 비교해 전송과 복구 결과를 확인합니다.
  • 사용자가 승인한 자동 작업에서 rclone과 Google Drive API를 사용합니다.

Google 계정 접근

앱에서 사용하는 특정 파일을 다루는 drive.file 권한을 요청합니다. Google 로그인과 접근 권한 동의는 사용자가 직접 진행합니다. 앱이 사용하는 파일의 읽기·수정·생성·삭제가 이 권한의 범위에 포함되며, 일반 보관 작업은 복사·검사·복구를 중심으로 수행합니다.

이 사이트는 도구의 소개와 데이터 처리 방침만 제공합니다. 파일 업로드나 Google 로그인 정보를 입력하는 화면은 제공하지 않습니다.
